# Architecture

Browser → React/Vite frontend (Nginx) → FastAPI → PostgreSQL 16 + pgvector. FastAPI → loopback Pi Coding Agent service → Ollama, Gemini, or Claude. Local ingestion and vector retrieval → Ollama `nomic-embed-text` (768 dimensions).

## Responsibilities and boundaries

FastAPI owns request validation, browser-workspace ownership, sessions, retrieval, structured SSE, transactional persistence, and health. The Pi SDK runs model inference with explicitly empty tools and isolated in-memory agent sessions. Provider choice is allowlisted. Ollama and Claude never silently fail over; Gemini failure or a 15-second timeout yields a visible, cited transcript-excerpt fallback instead of an invented answer.

The cloud call is Gemini generation through its OpenAI-compatible endpoint. There is no Crawl API or Gemini Search Grounding integration. The product grounds output through transcript excerpts retrieved from PostgreSQL. This avoids a separate crawler/search bill and preserves a reproducible archive, while giving up live-web discovery; that limit is explicit in the product and demo.

## Data and retrieval

`sessions` includes UUID, title, JSON metadata, `owner_token`, and timestamps. `messages` links session, role, text, source JSON, provider, mode, and completion status. `artifacts` links an assistant message to sanitized Markdown/HTML. `episodes` records source identity, checksum, and embedding model. `chunks` carries bounded transcript text, timestamp, and a 768-dimensional embedding, indexed with HNSW cosine search.

Local mode parses archive Markdown and frontmatter, chunks around paragraph/speaker boundaries, skips unchanged checksums, embeds with the pinned model, and retrieves cosine top-k above a threshold with per-episode diversity. Render’s free single-service mode uses PostgreSQL full-text ranking over the seeded archive, then applies the same bounded source-card shape. Empty/weak retrieval bypasses model generation with an explicit abstention. Citation validation confirms identifier membership, not semantic truth.

## API and resilience

`X-Workspace-Token` is required for session/chat/artifact endpoints. It is generated by the browser and scopes a visitor’s sessions. `POST /api/chat` uses an advisory lock per session, history from completed messages only, input/output bounds, a bounded model timeout, and cleanup that persists an interrupted result as failed. SSE emits `status`, `sources`, `token`, `artifact`, `warning`, `done`, or terminal `error`. `/api/health` reports database, archive, agent, provider, and embedding readiness.

## Security and deployment

HTML artifacts are sanitized, rendered in an empty sandbox, and covered by CSP; Markdown raw HTML is disabled. Secrets reside only in ignored environment files or Render secret variables. Docker Compose provides local reproducibility and database readiness. `Dockerfile.render` packages the frontend, FastAPI, and loopback agent into one Render web service; the managed database remains external. See `security.md` and `deployment.md` for public-scope limits.
